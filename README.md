# Pi-ICP
Physics-Informed ICP algorithm for deformation analysis and damage detection of vaulted building

## Requirements
- Rhino 8
- Numpy
- Scipy

## Content

- ***Pi_ICP.py*** - This is the code embedded in the .gh file so be readable online 
- ***Pi_ICP_Demo.zip***
  - Pi_ICP_Demo_Ver+OP45.3dm - Rhino file containing the undeformed template and the deformed mesh from FE synthetic data both as a mesh and as a point cloud  
  - Pi_ICP_Demo_Ver+Op45.gh - The Grasshopper file containing the .py script, pre and post processing
  - 45_UVEC_1.39 - The FE displacement field (U_FEM) used for comparison
